# Predicting the Future Prices of Agriculture

A web-based project for predicting future agricultural prices using crop, market area, forecast period, and current price data.

## Features
- User login
- Crop selection
- Market area selection
- Forecast period selection
- Agricultural price prediction
- Forecast chart
- Price table
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js

## Project Purpose
This project helps users understand possible future agricultural prices based on the selected crop, market area, forecast period, and current price.
